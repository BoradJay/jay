# Banker - Financial Services Website

A modern, responsive banking and financial services website built with HTML, CSS, and JavaScript. This website replicates the design and functionality of a professional banking platform with a clean, modern interface.

## 🌟 Features

### Design & Layout
- **Modern UI/UX**: Clean, professional design with gradient backgrounds and smooth animations
- **Fully Responsive**: Optimized for desktop, tablet, and mobile devices
- **Interactive Elements**: Hover effects, button animations, and smooth transitions
- **Professional Typography**: Using Inter font family for excellent readability

### Sections
1. **Header Navigation**: Fixed header with smooth scrolling navigation
2. **Hero Section**: Eye-catching landing area with call-to-action buttons
3. **Services**: 6 service cards showcasing banking offerings
4. **About**: Company information with animated statistics
5. **Testimonials**: Customer testimonials with auto-sliding carousel
6. **Call-to-Action**: Promotional section to encourage sign-ups
7. **Footer**: Comprehensive footer with links and social media

### Interactive Features
- **Mobile Navigation**: Hamburger menu for mobile devices
- **Smooth Scrolling**: Navigation links smoothly scroll to sections
- **Testimonials Slider**: Auto-rotating testimonials with manual controls
- **Scroll Animations**: Elements animate as they come into view
- **Counter Animations**: Statistics count up when visible
- **Button Effects**: Ripple effects and hover animations
- **Active Navigation**: Current section highlighting in navigation

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- No additional software required - runs entirely in the browser

### Installation
1. Download or clone the project files
2. Open `index.html` in your web browser
3. The website will load with all functionality ready to use

### File Structure
```
banker-website/
├── index.html          # Main HTML file
├── style.css           # All CSS styles and responsive design
├── script.js           # JavaScript functionality and interactions
└── README.md           # This documentation file
```

## 📱 Responsive Design

The website is fully responsive and optimized for:
- **Desktop**: 1200px+ (full layout with side-by-side content)
- **Tablet**: 768px - 1199px (adjusted grid layouts)
- **Mobile**: < 768px (stacked layout, mobile navigation)

## ⚡ Performance Features

- **Image Preloading**: Critical images are preloaded for faster loading
- **Debounced Scroll Events**: Optimized scroll performance
- **CSS Animations**: Hardware-accelerated animations
- **Minimal Dependencies**: Only uses Google Fonts and Font Awesome CDN

## 📝 Usage

### Navigation
- Click navigation links to smoothly scroll to sections
- Mobile users can use the hamburger menu
- Active section is highlighted in the navigation

### Testimonials
- Testimonials automatically rotate every 5 seconds
- Click the dots below testimonials to manually navigate
- Each testimonial includes customer photo, name, and role

### Buttons
- All buttons have hover effects and click animations
- Primary buttons have blue styling
- Secondary buttons have transparent styling

## 🎯 Key Features Explained

### Mobile Navigation
The hamburger menu appears on screens smaller than 768px and provides a smooth mobile navigation experience.

### Scroll Animations
Elements animate into view as you scroll down the page, creating an engaging user experience.

### Counter Animations
Statistics in the About section count up from 0 to their final values when they come into view.

### Testimonials Slider
A fully functional carousel that automatically rotates testimonials and allows manual navigation.

## 🛠️ Development

### Adding New Sections
1. Add HTML structure to `index.html`
2. Add corresponding CSS styles to `style.css`
3. Add any JavaScript functionality to `script.js`

### Modifying Colors
Update the CSS custom properties in `style.css` to change the color scheme.

### Adding Content
- Replace placeholder text in `index.html`
- Update images by changing the `src` attributes
- Modify service cards, testimonials, or other content as needed
