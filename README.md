# Banker - Banking Solutions Website

A modern, responsive banking website built with HTML, CSS, and JavaScript, inspired by the Colorlib Banker template. This website features a clean, professional design perfect for financial institutions, banks, and fintech companies.

## 🌟 Features

### 📱 Responsive Design
- Fully responsive layout that works on all devices
- Mobile-first approach with optimized navigation
- Fluid grid system and flexible images

### 🎨 Modern UI/UX
- Beautiful gradient color scheme (#667eea to #764ba2)
- Smooth animations and hover effects
- Glass morphism effects with backdrop blur
- Clean typography using Poppins font

### 🚀 Interactive Elements
- Mobile hamburger navigation menu
- Gallery with category filtering
- FAQ accordion functionality
- Contact form with validation
- Newsletter subscription
- Pricing cards with hover effects
- Smooth scrolling navigation

### 📋 Sections Included
1. **Hero Section** - Eye-catching introduction with service cards
2. **Features** - Key banking services highlights
3. **About Us** - Company information and values
4. **Team** - Meet the team members
5. **Gallery** - Filterable image gallery
6. **How It Works** - 3-step process explanation
7. **Services** - Detailed service offerings
8. **Testimonials** - Customer reviews
9. **Pricing** - Service pricing plans
10. **FAQ** - Frequently asked questions
11. **Blog** - Latest news and articles
12. **Contact** - Contact information and form
13. **Footer** - Additional links and newsletter signup

### ✨ Advanced Features
- Intersection Observer API for scroll animations
- Form validation with user feedback
- Notification system for user interactions
- Loading animations and transitions
- Parallax effects
- Custom scrollbar styling
- SEO-friendly structure

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- No server setup required - runs directly in the browser

### Installation
1. Download all files (`index.html`, `styles.css`, `script.js`)
2. Ensure all files are in the same directory
3. Open `index.html` in your web browser

### File Structure
```
banker-website/
│
├── index.html          # Main HTML file
├── styles.css          # CSS styles and responsive design
├── script.js           # JavaScript functionality
└── README.md          # Project documentation
```

## 🎯 Usage

### Navigation
- Use the top navigation menu to jump between sections
- On mobile, tap the hamburger menu (three lines) to access navigation
- All navigation links use smooth scrolling

### Gallery
- Click filter buttons (All, Events, Party, Holidays) to filter images
- Images animate smoothly when filtering

### FAQ Section
- Click on any question to expand/collapse the answer
- Only one answer can be open at a time

### Contact Form
- Fill out all required fields
- Email validation is performed automatically
- Success/error notifications appear after submission

### Pricing Plans
- Click "Buy Now" on any plan to see a notification
- Premium plan is highlighted as the featured option

## 🛠️ Customization

### Colors
The main brand colors can be changed in `styles.css`:
```css
/* Primary gradient */
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);

/* Update these values throughout the CSS file */
```

### Content
- Edit text content directly in `index.html`
- Replace images by updating the `src` attributes
- Add new sections by following the existing HTML structure

### Fonts
- Default font: Poppins from Google Fonts
- Change in the `<head>` section of `index.html` and update CSS

### Images
- Current images are sourced from Unsplash
- Replace with your own images by updating the `src` attributes
- Recommended image sizes:
  - Hero images: 1200x800px
  - Team photos: 300x300px
  - Gallery images: 500x400px
  - Blog images: 500x300px
